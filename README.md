# ParcialCVDS-CORTE1

## Patron de diseño seleccionado:

Para el parcial, el patron que decidi seleccionar es el de Observer.
La razon por la que se decicido seleccionar este patron es porque nos deja actualizar la informacion
de una clase para que funcione cuando esta informacion esta en una clase diferente. Con el observer, cada vez que la clase que tenga la informacion se actualiza, esta se puede actualizar en las clases que necesiten esa informacion.

En el parcial los agents son los que necesitan las informacion de los productos, cada vez que estos se actualicen para poder imprimir los mensajes necesarios.
